# Phase 4 — Windows Agent Deployment

## Objective

Deploy a Wazuh agent on a Windows machine and connect it to the Wazuh Manager running on Ubuntu Server.

## Step 1 — Configure the Windows Agent

1. Opened the Wazuh Dashboard.
2. Navigated to **Agents management → Deploy new agent**.
3. Selected **Windows — MSI 32/64 bits**.
4. Entered the Ubuntu Wazuh Manager's private IP address.
5. Assigned the agent name `Windows-SOC-Agent`.
6. Kept the agent group as `default`.

**Screenshot — Windows Agent Configuration**

![Agent Configuration](../screenshots/phase4-agent-configuration-redacted.png)

## Step 2 — Install the Agent Using PowerShell

Opened Windows PowerShell as Administrator and executed the installation command generated by Wazuh.

The installation command specified the Wazuh Manager address and the Windows agent name.

After installation, verified the service using:

```powershell
Get-Service -Name WazuhSvc
```

Initially, the service status was `Stopped`.

Started the service using:

```powershell
Start-Service -Name WazuhSvc
```

Checked again and confirmed that the service status changed to `Running`.

**Screenshot — PowerShell Installation and Service Verification**

![PowerShell Installation](../screenshots/phase4-powershell-redacted.png)

## Step 3 — Verify Agent Connectivity

Returned to the Wazuh Dashboard and navigated to **Agents management → Summary**.

Confirmed that the Windows endpoint appeared with the following details:

- **Agent name:** `Windows-SOC-Agent`
- **Operating system:** Windows 11 Pro
- **Agent group:** `default`
- **Connection status:** Active

**Screenshot — Active Windows Agent**

![Active Windows Agent](../screenshots/phase4-agent-active-redacted.png)

## Results

The Windows agent was successfully installed, started, and connected to the Wazuh Manager.

**Phase 4 Status: Completed**

The Windows endpoint is now connected to the SIEM and ready for security monitoring and threat detection.
