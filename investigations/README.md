# SOC Incident Investigations

This directory contains hands-on Security Operations Center (SOC) investigation case studies performed using my Wazuh SIEM home lab.

Each investigation focuses on analyzing security events, identifying suspicious activity, correlating endpoint evidence, assessing potential threats, and documenting incident response recommendations.

## Investigation Cases

| Case | Investigation | Status |

| INC-001 | Phishing Email Investigation | In Progress |

## Investigation Tools

- Wazuh SIEM — Threat Hunting and security event analysis
- Sysmon — Windows endpoint telemetry
- Windows Event Viewer — Security event investigation
- PowerShell — Log analysis and evidence collection
- MITRE ATT&CK — Threat behavior classification

## Investigation Methodology

Each case study follows a structured SOC workflow:

1. Alert or incident intake
2. Initial triage
3. Evidence collection
4. Event correlation and threat analysis
5. Impact and severity assessment
6. Containment and remediation recommendations
7. Final incident report

All investigations are conducted in a controlled home lab environment using simulated security scenarios.
